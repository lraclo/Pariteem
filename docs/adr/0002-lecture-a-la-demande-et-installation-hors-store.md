# Lecture uniquement à la demande, installation hors Chrome Web Store

L'extension ne lit les cotes qu'au clic sur « Chercher », jamais en continu ni automatiquement à l'arrivée sur le site (le badge signale seulement un Bookmaker pris en charge) : les CGU des Bookmakers interdisent souvent la collecte automatisée et le risque principal est la fermeture du compte d'un Titulaire. Pour la même raison de fond, elle n'est pas publiée sur le Chrome Web Store, dont le règlement interdit les extensions qui « facilitent ou promeuvent les jeux d'argent réel » (paris sportifs compris, y compris en non répertorié) ; chaque membre la charge en mode développeur (voir ADR 0003).

## Consequences

Les mises à jour sont manuelles, et Chrome peut afficher un avertissement sur les extensions en mode développeur.
